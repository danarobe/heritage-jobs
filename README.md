# 🏛️ 문화유산 채용 보드

문화재·문화유산 분야 채용공고를 여러 사이트에서 자동으로 모아 관심도 순으로 보여주는 웹 페이지입니다.

## 어디서 모으나

| 출처 | 방식 |
|---|---|
| 사람인 | "문화재, 문화유산, 국가유산, 학예, 발굴, 보존처리" 검색 |
| 잡코리아 | 같은 검색어 + 관심도 높은 공고는 상세 페이지에서 시작일·마감일·모집요강 보강 |
| 국가유산청 시험/채용 게시판 | 본청 + 소속 연구소·박물관 공고 전부 |
| 국립문화유산연구원 채용정보 | 본원 + 지방 연구소 |
| 국가유산진흥원 인재채용 | 게시판 전체 |
| 잡알리오(공공기관) | 제목 검색 (유산, 문화재, 학예, 박물관, 발굴) |
| 나라일터(인사혁신처) | 검색 (지자체 문화재단·박물관 공고가 많음) |

## 어떻게 돌아가나

- `scripts/crawl.mjs` 가 위 출처를 돌며 `data/jobs.json` 을 만듭니다.
- GitHub Actions(`.github/workflows/crawl.yml`)가 매일 07:30 / 12:30 / 18:30(한국시간)에 자동 실행해 결과를 커밋합니다.
- `index.html` 은 `data/jobs.json` 을 읽어서 보여주는 정적 페이지 → GitHub Pages 로 배포.

## 관심도 점수

`config/interests.json` 에 분야별 키워드와 가중치가 있습니다. 제목에 있으면 3배, 기관명 2배, 본문 1배.
"딱 맞음(15점 이상) / 관련 있음(8점 이상) / 관련 낮음" 으로 나뉩니다.
관련 없는 직무 단어(`noise`)가 제목에 있으면 점수를 크게 깎습니다.
키워드를 바꾸고 싶으면 이 파일만 고치면 됩니다.

## 직접 실행

```bash
npm install
node scripts/crawl.mjs            # 전부 수집
node scripts/crawl.mjs saramin khs  # 일부 출처만
node scripts/serve.mjs            # http://localhost:3005 에서 미리보기
```
